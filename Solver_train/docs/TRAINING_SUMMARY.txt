================================================================================
CHESS PIECE CLASSIFICATION VIA TRANSFER LEARNING ON RESNET-18
Technical Summary for Scientific Paper
================================================================================

1. OVERVIEW
-----------
This work presents a supervised image classification pipeline for chess piece
recognition. Two independent binary/multi-class classifiers are trained using
transfer learning on a pretrained convolutional neural network. The classifiers
are intended to be applied to board-square crops extracted from chess board
photographs, enabling automated board state reconstruction.


2. DATASET
----------
The dataset consists of 4,557 labeled images of individual chess pieces, drawn
from two publicly available computer-vision chess datasets:

  - chess-cv-chessvision  (Kaggle / ChessVision project)
  - chess-cv-openboard    (Kaggle / OpenBoard project)

Images are organized into 12 class folders corresponding to the Cartesian
product of 6 piece types and 2 colors, using standard algebraic notation:

  White pieces: wP (pawn), wN (knight), wB (bishop), wR (rook), wQ (queen), wK (king)
  Black pieces: bP (pawn), bN (knight), bB (bishop), bR (rook), bQ (queen), bK (king)

Class distribution (images per class):

  Class    Count
  ------   -----
  wP       1143
  bP       1137
  wR        333
  bR        333
  bB        242
  wB        239
  bK        216
  wK        204
  wN        207
  bN        188
  bQ        153 (*)
  wQ        162

  (*) Queen classes are the least represented; pawn classes dominate the dataset.

The dataset was partitioned into training and validation splits:
  - Training set:   3,652 samples (~80%)
  - Validation set:   905 samples (~20%)

Splits were generated automatically from the flat per-class folders (no
pre-defined train/val separation was used from the original sources).

All images were resized to 128 x 128 pixels prior to training.
Pixel values were normalized using ImageNet statistics:
  Mean:  (0.485, 0.456, 0.406)
  Std:   (0.229, 0.224, 0.225)


3. MODEL ARCHITECTURE
---------------------
Both classifiers share the same backbone architecture:

  Base model:   ResNet-18 (He et al., 2016)
  Weights:      Pretrained on ImageNet (ILSVRC)
  Fine-tuning:  Full network (all layers unfrozen)
  Head:         Final fully-connected layer replaced with a task-specific
                linear layer (output size = number of classes for that task)

Transfer learning from ImageNet pretraining allows the model to leverage
general low-level visual features (edges, textures) while adapting the
higher-level representations to the chess domain.

Framework: PyTorch + torchvision


4. CLASSIFIERS TRAINED
----------------------
Two separate models are trained from the same dataset:

  (A) PIECE TYPE CLASSIFIER  [type_classifier.pt]
      Task:     Multi-class classification
      Classes:  6 — pawn, knight, bishop, rook, queen, king
      Output:   Softmax over 6 logits

  (B) PIECE COLOR CLASSIFIER  [color_classifier.pt]
      Task:     Binary classification
      Classes:  2 — white, black
      Output:   Softmax over 2 logits

The two-classifier design decouples piece identity from piece color, allowing
each model to specialize on its respective visual cues independently.


5. TRAINING CONFIGURATION
--------------------------
  Optimizer:       Adam
  Epochs:          15
  Batch size:      32
  Image size:      128 x 128 px
  Loss function:   Cross-entropy

Both classifiers converge rapidly and achieve perfect validation accuracy by
epoch 11-13, reflecting the discriminative nature of the task and the quality
of the pretrained features. The color classifier converges faster (high
accuracy from epoch 1) as distinguishing piece color is a simpler visual task
than recognizing piece type.


7. INFERENCE
------------
At inference time, a chess board image is divided into an 8x8 grid of square
crops. Each crop is passed through both classifiers independently. The combined
prediction assigns each square a piece type and a piece color, enabling full
board state reconstruction in FEN-compatible notation.
